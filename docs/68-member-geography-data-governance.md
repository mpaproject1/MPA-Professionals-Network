# Member Geography Baseline, Governance and Workbook Operations

## Baseline reference package

The starter geography workbook is generated by `scripts/generate-member-geography-reference.js` and validated by `scripts/validate-member-geography-reference.js`.

It contains:

- UN Statistics Division M49 country/area entries with ISO alpha-3 and three-digit M49 identifiers. The M49 list is a statistical reference and does not make a statement about sovereignty or legal status.
- Ethiopia (ETH), M49 231.
- Ethiopia's 12 regions and two chartered cities, using stable MPA internal unit codes. These codes are not represented as official Ethiopian government codes.
- Row-level HTTPS source provenance and source-version metadata.

Primary sources:
- UN Statistics Division M49: https://unstats.un.org/unsd/methodology/m49/overview/
- PCGN reference cited by the UK Home Office Ethiopia CPIN (September 2025): https://www.gov.uk/government/publications/ethiopia-country-policy-and-information-notes/country-policy-and-information-note-internal-relocation-ethiopia-september-2025-accessible

The baseline intentionally does not invent Ethiopian Zones, Sub-cities, Districts or Towns. It also does not infer provinces, states or cities for other countries. For non-Ethiopian residence, the supported reference is the country/area; a member may add a free-text diaspora area.

## Hierarchy and validation contract

- Country: no parent; requires ISO alpha-3 and UN M49 codes.
- Region or Federal City: parent must be Ethiopia (ETH).
- Zone: parent must be a Region.
- Sub-city: parent must be a Federal City.
- District or Town: parent must be a Zone or Sub-city, matching the member-residence selector's three administrative levels.
- Every imported row has a stable unique unit code, label, source name, source version, HTTPS row-level `metadata.sourceUrl`, and valid effective dates.
- Parent references must resolve within the same workbook/version. Country ISO/M49 uniqueness is enforced by database indexes.
- Only active countries marked residence-selectable appear in member country selection.

## First-time initial publication

1. Open the Member geography reference workflow in GitHub Actions and run it on the target branch.
2. Download the generated `member-geography-reference` artifact, including the XLSX workbook and manifest.
3. In Admin → Membership Center → Member geography, upload the workbook and enter the workbook source name, version and primary HTTPS source URL.
4. Preview and resolve every validation error. Applying creates a draft version only.
5. Review the source and hierarchy, enter the audit reason, and publish. Publishing switches member selectors to the new version; it does not mutate earlier versions.

The repository workflow creates and validates the starter workbook. It does not connect to or silently seed a production database. Initial publication is an explicit administrator action in the target environment.

## Export, amend and re-import

1. Use **Export published geography** to download the exact currently published version as XLSX.
2. Amend labels, activity, source provenance or hierarchy while preserving stable `unit_code` values and the complete required column set.
3. Add new Ethiopian administrative rows only with an authoritative source, stable parent codes and HTTPS row-level provenance.
4. Upload the amended workbook and preview it. An import creates a new draft version; it never edits a published version in place.
5. Apply and publish only after the preview is clean and the audit reasons are recorded.

Do not remove a country or unit that is referenced by historical member residences without considering those retained version references. Published versions are immutable historical snapshots.
